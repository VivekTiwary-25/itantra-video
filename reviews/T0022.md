1. **Black-frame parsing:** ffmpeg 9 prints `black_start` and `black_end` on one line. The parser read only the first match, so every black run looked open-ended (sonar_a reported "black 0-7 s", a joined preview "black 0-31 s"). It now reads every match on a line.
