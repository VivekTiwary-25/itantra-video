## Goal
The agents cannot hear, so Vivek picks the small sounds by ear. Make a tidy options pack, all generated procedurally (Python/numpy, deterministic, no downloads, no samples).

## Details
Make 3 clearly different options for each of these, each as 48 kHz stereo WAV, peak at -12 dBFS, with short fades so nothing clicks:
1. **Message notification** (a generic phone notification: friendly, short, 0.4-0.8 s; not a copy of any real phone's sound).
2. **Sent confirmation** (a soft two-note blip, under 0.4 s).
3. **Callout tick** (very soft, under 0.15 s) for line landings and the title card.
4. **SOS notification** (clearly more urgent than the message notification but controlled: no siren, no boom; 0.8-1.4 s).
5. **SOS sonar pulse** (soft, low, controlled; a single pulse about 1.2 s).
Put the generator in `film/sound/make_options.py` (it writes into `RENDERS:sound_options/` using `machine.local.json`, and also accepts `--out <dir>`). For the repo, commit only small previews: one MP3 per sound at 96 kbps in `results/T0024/preview/` (each under 100 KB), plus a single `all_options.mp3` that plays every option in order with a 0.6 s gap, and a text file listing the order with timestamps so Vivek knows which is which.
Also measure and report each option's loudness (LUFS) and spectral centre, and say in one line what it should feel like.

## Done when
15 options generate reproducibly, the preview MP3s and the ordered list exist, and REPORT.md recommends one per category.
