## Goal
Vivek is recording the narrator lines himself on his phone (N1, N2, N3, N5, N6; N4 is dropped). Build the tool that turns his raw files into film-ready narration, so the swap is one command on vivek-pc.
## Details
`python film/narration/prep.py` must:
1. Read every file in `local/narration_vivek/` (any of m4a, mp3, wav, aac, ogg; names like `N1`, `N1_a`, `N1_b`; case-insensitive). If a line has several takes, process all and pick the one closest to its target length that is not clipped, and say which.
2. Clean each the same way as scene 1's voice: the `CHAIN` string in `film/scene1/build.py` (it uses RNNoise model files at `local/models/rnnoise/`; if they are missing, fall back to the chain without the two `arnndn` steps and say so loudly). Then trim leading and trailing silence to 30 ms, 48 kHz mono, and loudness-match to the dialogue level used in the scenes (-16 LUFS for dialogue; narration at -18 LUFS before the mix, as the current david files are).
3. Compare each length with its target and max (section F of `discussion/v2/001-claude-lead.md`). Over the max: time-compress with `atempo` by at most 6% and report; still over: report clearly and keep the line (the lead decides).
4. Write `RENDERS:narration/vivek/N1.wav`, `N2.wav`, `N3.wav`, `N5.wav`, `N6.wav`, a `report.json` (take chosen, raw length, final length, target, stretch applied), and set `film/common/narration.json` to `{"voice": "vivek"}` only if all five lines exist; otherwise leave it and list what is missing.
Test it with synthetic inputs (generate five speech-like test files with ffmpeg, e.g. band-limited noise bursts of the right lengths, some with long silences and one too long) and show the run.
## Done when
`prep.py` handles the synthetic set end to end and REPORT.md gives the exact command for vivek-pc.
