## Goal
Find where each separately recorded clean audio file lines up with its video, so the edit can replace the camera sound. No editing.

## Details
Pairs (resolve with `$FOOTAGE_ROOT`; quote paths, some names have spaces; names match ignoring case):
- `Video/normalpart1.mp4` + `Audio/normalpart1.mp3`
- `Video/normalpart6.mp4` + `Audio/Normalpart6.mp3`
- `Video/sospart1.mp4` + `Audio/sospart1.mp3`
- `Video/sospart2.mp4` + `Audio/sospart2.mp3`
- `Video/vachna part1.mp4` + `Audio/vachna part1.mp3`
- `Video/vachna part2.mp4` + `Audio/vachna part2.mp3`

For each pair:
1. Decode the video's camera audio and the clean mp3 to mono 16 kHz with ffmpeg (into `local/tmp/`).
2. Cross-correlate (use numpy/scipy if importable; if not, write a small FFT correlation in plain Python; do not try to install anything, there is no internet). Use a band-passed (300-3400 Hz) signal or an onset/energy envelope, whichever gives a clearer peak.
3. Report `offset_s` defined as: **the clean-audio sample at time t plays at video time t + offset_s** (so a positive value means the clean audio starts after the video starts). Give it to the millisecond.
4. Confidence: peak height divided by the second-highest peak outside +/-0.2 s. Call it `high` (>= 2.0), `medium` (1.4-2.0) or `low` (< 1.4).
5. Drift: repeat the correlation on the first third and the last third separately (search +/-0.5 s around the global offset). Report both offsets and the difference in ms.
6. Note which parts of the clean audio fall outside the video (before 0 or after the video's end).

Write `results/T0002/sync.json` (`[{pair, video, audio, offset_s, confidence, peak_ratio, drift_first_s, drift_last_s, drift_ms, clean_outside_video}]`), `results/T0002/sync.md` (plain table plus a one-line verdict per pair), and the script as `results/T0002/sync.py` (paths read from `machine.local.json` / `$FOOTAGE_ROOT`, never hard-coded). Flag clearly any pair whose confidence is not high.

## Done when
All six pairs have an offset, confidence and drift figure, or a clear reason why not.
