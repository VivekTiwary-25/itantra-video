## Goal
Prove that HyperFrames works for workers on utkarsh-pc (Chrome, ffmpeg and the local GSAP copy all reachable inside the sandbox). The same job already passed on another machine (X014).

## Details
Set env `HYPERFRAMES_NO_TELEMETRY=1` and `HYPERFRAMES_SKIP_SKILLS=1` for every command. Use the `.cmd` shim: run `hyperframes.cmd`, not `hyperframes` (the .ps1 shim may be blocked).
1. From inside `results/X015/`, run `hyperframes.cmd init project --non-interactive --skip-transcribe`.
2. Copy `film/vendor/gsap/gsap.min.js` into `results/X015/project/`. In `results/X015/project/index.html` remove any `<script src="https://...">` tag and use `<script src="./gsap.min.js"></script>` instead. No URLs anywhere in the file.
3. Edit `index.html`: 1920x1080, background #0a0a0a, the word `iTantra` centred in near-white (#f4f4f5), 72px, the text element starts with `style="opacity:0"` and GSAP fades it to opacity 1 between t=0.3 s and t=1.5 s (`tl.fromTo("#title", {opacity:0, y:24}, {opacity:1, y:0, duration:1.2, ease:"power2.out"}, 0.3)`). Root composition and the text both have `data-duration="3"`.
4. Run `hyperframes.cmd check` inside `results/X015/project/`. It must pass with 0 errors. If it fails, report the exact reason and set `status: failed`. Do not hide it.
5. Run `hyperframes.cmd snapshot --at 0.2,1.5 --no-end -o snaps` inside the project folder. Copy the PNGs to `results/X015/preview/snapshot-0.2s.png` and `results/X015/preview/snapshot-1.5s.png`, then delete the `snaps` folder. The 0.2 s frame must be empty dark and the 1.5 s frame must show the word, otherwise the fade is not working. Do NOT render an mp4.
6. If `check` or `snapshot` cannot find a browser (Chrome), say so plainly in the report and set `status: failed`; do not look for other browsers or install anything.
7. `results/X015/REPORT.md` must start with a front-matter block containing `status: done` (or `failed`), list the commands you ran, and say what the 0.2 s and 1.5 s frames show. Never write absolute paths, user names or emails (this repo is public).

## Done when
`hyperframes.cmd check` passed, and the two PNGs exist and show empty-then-text.
