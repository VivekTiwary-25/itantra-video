## Goal
Scene 2 needs a narrator. For now it's a computer voice. Vivek may re-record these lines later, so every line is short and fixed.

## Details
Lines (exact text):
- N1: "Let's see how far that message actually has to travel."
- N2: "But how did that happen? Bluetooth doesn't reach that far."
- N3: "And that's how it gets there."
- N4: "His reply comes back the same way."

1. List the installed Windows voices, both SAPI (`System.Speech`) and OneCore/WinRT (`Windows.Media.SpeechSynthesis.SpeechSynthesizer.AllVoices`, callable from PowerShell). Prefer an **English (India)** voice (e.g. Microsoft Heera / Ravi / Neerja / Prabhat) if one is installed. Otherwise use the most natural en-US or en-GB voice. Use only voices already installed: no internet, no downloads.
2. Synthesize each line with up to 3 different voices (a calm, clear, unhurried read; slightly slower than the default rate is fine) as WAV. Then convert with ffmpeg to 48 kHz mono 24-bit, trim leading and trailing silence to 30 ms, and normalise each to -18 LUFS.
3. Save to `local/renders/scene2/narration/<voiceshortname>/N1.wav` ... `N4.wav` (git-ignored).
4. Write `results/T0005/narration.json`: `{voice: {line: {text, duration_s}}}` plus `recommended_voice`, and the synthesis script as `results/T0005/tts.ps1` (or `.py`), with no absolute paths.
