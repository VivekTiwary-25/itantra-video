## Details
Clips: all 10 files in `FOOTAGE:Video/` (resolve with `$FOOTAGE_ROOT`, or `footage_root` in `machine.local.json`). File names contain spaces (`vachna part1.mp4`), so quote paths.

1. **Frame grids.** For each clip, take one frame every 1 s (every 2 s for `normalpart2`, which is 202 s long). Scale each frame to 384x216 and burn the source timecode (seconds, one decimal, e.g. `37.0s`) in small white text on a dark box in a corner. Tile 5 columns x 4 rows per sheet (20 frames). Save as JPEG quality 80 to `results/T0001/grids/<clip name with spaces as underscores>_NN.jpg`. Each JPEG must be under 1 MB.

3. Also write `results/T0001/moments.json` with the same data: `[{clip, start_s, end_s, beat, person, screen, readable, notes}]`.
