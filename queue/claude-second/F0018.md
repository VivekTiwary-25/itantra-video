## Note
Draft-mode tests with slates and short ffmpeg jobs are fine on your laptop; no full-length video renders there (the lead runs the real assembly on utkarsh-pc).

## Goal
One command that turns the rendered v3 segments into `RENDERS:full_film_v3.mp4`, with dialogue, sound and the film-wide music bed mixed, and runs QC. The lead runs it over SSH on a render machine (utkarsh-pc first) once the segments are rendered.

## Details
1. Read every v3 segment folder (intro_v3, scene2/v3a, scene2/v3b, scene3/v3, exploded, cards_v3; some may not exist yet) and its build/render script, and work out exactly what each produces: picture file, and audio stems (dialogue/narration/TTS, sfx). Write `film/final/v3_segments.json`: ordered list of {name, folder, render_cmd, video: "RENDERS:...", stems: {dx: ..., sfx: ...}, tts_windows: [[start,end] in segment seconds], expected_duration}. Where a segment's build does not write separate stems yet, note it and use what exists (e.g. a mixed track) as `dx`.
2. `film/final/assemble_v3.py [--segments film/final/v3_segments.json] [--draft]`: resolves RENDERS: via machine.local.json; checks every file exists and has the expected duration (fail loudly; `--draft` substitutes a 2 s dark slate with the segment name for a missing segment and lists it); concatenates pictures (re-encode once to H.264 yuv420p 1920x1080 30 fps CRF 18, or stream-copy if all match exactly); builds the dialogue+sfx stem on the film timeline; writes film-level `film/music/cues.json` section starts from the real segment starts if `film/music/make_bed.py` exists, runs it, then `duck.py` against the dialogue stem with the TTS windows; mixes (dialogue at its level, sfx as rendered, ducked bed); masters to -16 LUFS integrated, true peak <= -1.5 dBTP (two-pass loudnorm or a linear gain + the limiter approach already in `assemble.py`); muxes AAC 48 kHz stereo 256 kbps. Outputs: `RENDERS:full_film_v3.mp4`, `RENDERS:full_film_v3_nomusic.mp4`, `RENDERS:full_film_v3_stems/{dx,sfx,music}.wav`, `RENDERS:full_film_v3_report.json` (segment starts, lengths, loudness).
3. Extend `film/final/qc.py` (keep old behaviour) with a `--v3` mode: frozen-frame detection reported per segment with times (the film rule is that live camera never freezes; list every freeze >= 0.5 s so the lead can check each), black frames, loudness/peak, silence > 1.5 s (INFO only for the cards), A/V duration alignment, and a contact sheet every 5 s to `RENDERS:full_film_v3_contact.jpg` (and a 960 px copy for results).
4. Test it now in `--draft` mode with whatever renders exist on this machine (slates for the rest), short of a full render; put the test report and a small contact sheet in `results/F0018/`.
5. `film/final/README_v3.md`: the exact commands for the lead (render each segment, then assemble, then QC).

## Done when
Script, segments file, QC mode and README committed; the draft test ran end to end with slates.
